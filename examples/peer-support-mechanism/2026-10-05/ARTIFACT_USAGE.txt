Peer-support figure: measured aggregates and synthetic mathematical examples

Run from this directory with NumPy and Matplotlib installed:
    python plot_support.py --input v54_support_counts.json --output my-new-figure

The output prefix must be fresh. The script writes a PNG, SVG and JSON provenance record. It loads no model, patient record, target table or checkpoint. SVG and PNG are generated by Matplotlib; the figure contains no AI-generated scientific evidence.

Panels A and C reproduce the exact deidentified epoch-2 support counts from the incomplete V54 native trial. Source version54/native SHA1d9265cbf224641e22b89235182179e339fe801057e2894c6de0ebd862955585. Both peer networks had identical aggregate counts, which does not establish identical selected examples. V54 ended HOLD_NATIVE_TRIAL after2/4 epochs; its partial checkpoints remain ineligible. The chart establishes no accuracy, throughput or official-score gain.

Panel B illustrates the original max(1,floor(.8*n)) rule for a single finding/class stratum of1..4 cells. Panel D uses only synthetic y values and the identity BCE(y,p)=H(y)+KL(Ber(y)||Ber(p)). At p=y, raw BCE equals target entropy. Low raw loss can favor high-confidence soft targets; this is a mathematical mechanism, not evidence that any particular actual targets were wrong. Report-derived soft target>.5 is not a verified diagnosis.
