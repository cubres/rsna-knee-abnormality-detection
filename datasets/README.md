# Datasets

Cards for public Kaggle datasets. Each folder holds the dataset card, its metadata and checksums and its cover image. The data files are on Kaggle.

- [RSNA Knee 2026: One Team's Submissions, Scored](https://www.kaggle.com/datasets/prvsiyan/rsna-knee-2026-experiment-ledger) (`rsna-knee-2026-experiment-ledger/`)
- [RSNA Knee Fail-Closed Reader + Gate (Python code)](https://www.kaggle.com/datasets/prvsiyan/rsna-knee-reader-code-pack) (`rsna-knee-reader-code-pack/`)
- [RSNA Knee Inference Timing T4](https://www.kaggle.com/datasets/prvsiyan/rsna-knee-inference-timing-t4) (`rsna-knee-inference-timing-t4/`)
- [Hidden-Rerun Safety Kit: Checklist + Tested Code](https://www.kaggle.com/datasets/prvsiyan/kaggle-hidden-rerun-safety-kit) (`kaggle-hidden-rerun-safety-kit/`)
- [RSNA Knee 2026: public notebook scores and assets](https://www.kaggle.com/datasets/prvsiyan/rsna-knee-2026-public-notebook-scores-and-assets) (`rsna-knee-2026-public-notebook-scores-and-assets/`)
