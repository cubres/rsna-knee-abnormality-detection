# Measured figures and diagrams

`V59_EXPOSED_PROXY_COMPARISON.svg` and `.png` are the original measured charts prepared from independent V59 qualification SHA `9e6b4ac32bda0d80579a40e5ded75997636f018a7b90ae49a01451c64c455d02`. Both were copied byte-for-byte. The chart shows exact macro AUCs and paired differences with pointwise descriptive 95% intervals. Its AUC axis is deliberately zoomed and printed values show the scale; the difference panel includes zero. The footer states the exposed-panel and nonofficial limits.

The portable `tools/plot_proxy_result.py` is adapted from the original chart generator to read the distributed scalar projection. It redraws the same measured values and interval endpoints. Font, backend and timestamp metadata can change file bytes; visual and numeric agreement are the relevant reproduction checks. Original plot source SHA is `254b8c479b824c4a57a4884ce5b71149543a5af90400cbfefbe8286fed968f84`.

`evidence_flow.svg` and `.png` are original explanatory diagrams. Their box and arrow positions illustrate the two evidence paths; they are not medical imagery or measured scientific geometry. All displayed counts and runtime come from the hash-pinned scalar evidence. No new AI-generated artwork is used in this outcome packet; the earlier source release retains its separately documented artwork.

These visuals contain no patient identifiers, MRI, model weights, source reports or study-level target/prediction values. The public tools create a new output directory and do not execute models or read private study data.
